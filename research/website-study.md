# Website source and messaging study

**Review date: October 4, 2026 · Scope: nine public HTML surfaces**

The [snapshot manifest](website-snapshots/manifest.json) records requested/final URL, HTTP status, UTC retrieval time, document title, byte count, SHA-256, and local HTML copy for every inspected page. All nine HTTP fetches returned 200. Two pages were unavailable through the web extraction tool; direct HTTP snapshots established their accessible HTML. This is a source/content review, not an attestation of interactive behavior, calculations, accessibility, or full-site coverage.

## Coherence and reader opportunities

The shared theme is that evidence must remain traceable as a program's assumptions and dependencies change. The website supplies concise entry points; repository documents provide the detailed method. The short playbook should bridge them with one understandable story and progressive depth.

The Atlas is especially useful for public comprehension because it shows where a pathway's reviewed evidence ends. FMA gives the strongest flagship changed-state illustration. FIW's three-reports/one-root case is a simpler opening for readers unfamiliar with frontier engineering.

Current terminology includes Frontier Intelligence, Frontier Assurance Infrastructure, Mission Assurance, Strategic Resilience, Materials-to-Mission, and several profile names. The playbook should define the practical responsibility behind each term. It should not present every architectural role as a separately available public product.

## Gaps and next evidence

The nine surfaces reviewed do not establish named customer outcomes, delivery economics, funding history, team identity, company legal records, or quantified benefit. This is a scoped research finding, not a statement that such information does not exist. Obtain approved facts from the user if they are useful to the public narrative.

The actual website source repository and publication pipeline were not established. GitHub Pages hosting does not identify the source checkout or authorize changing it. A concrete local preview can be prepared now; actual integration needs the source location and agreed publication target.

Rendered interaction, keyboard/screen-reader behavior, mobile layouts, calculation outputs, and performance of the original website remain outside this source review. The publication candidate needs its own checks. Existing source studies and this report contain no fresh operational or customer proof.
